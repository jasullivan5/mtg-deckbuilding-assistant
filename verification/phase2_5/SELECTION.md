# Phase 2.5 selection (before extraction changes)
The Phase 2.4 extractor has one native `walk`, shared action/binding frames, facts for movement and death operations. `Reanimation` only queries facts; `MechanicalQuery` retains death policy. The new objective will not walk SDK nodes.

Selected bounded interpretations:
1. Native CreateToken and CreatePredefinedToken: preserve native templates, count expressions and receiver. Resolve predefined characteristics through upstream PredefinedTokens, never token-name tables. Unknown templates remain unknown. Development cases: Dragon Fodder, Krenko, Big Score, Hunted Horror.
2. CreateTokenBatch: traverse groups inside the existing walk with shared controller/event, separate correlated group facts. Synthetic positive/adversarial fixtures; inspect authored use before claiming real batch coverage.
3. CreateTokenCopyOfSource/Target: native merged CopyExceptions type replacement/addition, source/target binding, controller independent of copied-object control. Heat Shimmer motivates. Other copy primitives remain unsupported. Animated noncreature status is not proof of copiable creature characteristics.

All counts are conditional potentials: positive fixed quantity supported; native variable counts retain positive-count/resource prerequisites. Stored/unbound/dynamic conditional semantics remain unknown. Do not change death AmountBounds semantics.

Freeze source-led Oracle/ruling expectations in benchmark/phase25/review-v1.json before edits. This is same-reviewer source verification, not an external gold standard. Reserve Hordeling Outburst, Goblin Rabblemaster and Raise the Alarm as held-out transfer cases. White cards need a suitable additional Commander context for benchmark evaluation and are not counted as Judith/Krenko extraction failures.

Validate boundaries with native synthetic definitions, existing engine scenarios plus actual token resolution tests, full A/B comparisons on identical eligible pools. Narrow common result projection may be extracted from Reanimation, preserving its content. Preserve all previous test sources.
